# 業務日報 提出管理

1人用のシンプルな業務日報提出状況管理Webアプリです。今日の日報を提出済みにした時刻と、月ごとの提出状況を確認できます。

## ファイル構成

- `index.html`：画面の構造
- `style.css`：デザイン
- `app.js`：提出記録・月間表示の処理
- `README.md`：この説明書

## GitHub Pagesで公開する方法

1. この4ファイルをGitHubリポジトリのルートにアップロードします。
2. リポジトリの **Settings** → **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選びます。
4. 公開するブランチ（通常は `main`）とフォルダ（`/(root)`）を選び、**Save** を押します。
5. 数分後に表示されるURLを開くとアプリを利用できます。

## データの保存について

提出履歴は、ブラウザの `localStorage` に日付ごとに保存されます。ページを閉じたり再読み込みしても、同じブラウザでは記録が残ります。

`localStorage` のデータはGitHubやサーバーには保存されません。そのため、別のPC・スマートフォン・ブラウザとは記録が同期されません。
