# 業務日報 提出管理

1人用の、シンプルな業務日報の提出状況確認Webアプリです。今日の日報を提出済みにし、当月の営業日ごとの提出状況と提出時刻を確認できます。

## ファイル構成

- `index.html`：画面の構造
- `style.css`：見た目とスマートフォン向け表示
- `app.js`：提出登録、月間一覧、保存処理
- `README.md`：この説明書

## GitHub Pagesで公開する方法

1. この4ファイルをGitHubリポジトリの一番上の階層にアップロードします。
2. GitHubのリポジトリで **Settings** → **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選びます。
4. Branch を `main`、フォルダーを `/(root)` にして **Save** を押します。
5. 数分後に表示されるURLを開くと公開ページを確認できます。

## データの保存について

提出履歴は、ブラウザの `localStorage` に日付ごとの提出日時として保存されます。そのため、ページを閉じたり再読み込みしたりしても、このブラウザでは提出状態が残ります。

`localStorage` はブラウザと端末ごとに保存されます。別のPC・スマートフォン・ブラウザとはデータが同期されません。また、ブラウザのサイトデータを削除すると提出履歴も消えます。
